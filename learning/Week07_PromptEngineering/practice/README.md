# Week07 Practice Overview

`practice/` 是 Prompt Engineering（提示工程）所有練習的唯一入口。

## 練習檔案

| 路徑 | 用途 |
| --- | --- |
| `concept/concept_practice.md` | Prompt、schema、unknown、retry 與 safety 題目。 |
| `concept/concept_answer_key.md` | 完成後查看的參考答案。 |
| `coding/README.md` | Guided Code Reading 說明。 |
| `coding/coding_practice.md` | Prompt contract、validation、retry 與 safety 觀察表。 |
| `coding/coding_observation_key.md` | 完成後查看的觀察方向。 |
| `coding/guided_demos/` | 四個完整可執行流程。 |

## 建議順序

1. 執行五個 Demo。
2. 完成 Concept Practice。
3. 依序執行四個 Guided Demo。
4. 在 Coding Practice 設計 Prompt、test matrix 與處置政策。
5. 最後查看參考答案，並將結果整理到 `../study_log.md`。

## 本週 Coding Practice 模式

本週採 Guided Code Reading Mode。重點是理解與觀察 Prompt 到安全語意輸出的流程，不從零實作 VLM，也不建立 TODO 練習檔。
