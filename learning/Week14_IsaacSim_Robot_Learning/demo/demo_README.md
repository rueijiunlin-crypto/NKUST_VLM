# Week14 Demo Guide

| Demo | 指令 | 目的 | 限制 |
| --- | --- | --- | --- |
| Experiment config | `python demo/demo_01_sim_experiment_config.py` | 完整列出模組／metric | 不啟動 Isaac Sim |
