# Week06 Practice Overview

`practice/` 是本週論文閱讀練習入口，包含觀念題與結構化閱讀程式。

## 練習檔案

| 路徑 | 用途 |
| --- | --- |
| `concept/concept_practice.md` | 研究問題、證據、指標、消融與限制題目。 |
| `concept/concept_answer_key.md` | 完成後查看的參考答案。 |
| `coding/README.md` | 程式閱讀說明。 |
| `coding/coding_practice.md` | 閱讀流程與學生紀錄表。 |
| `coding/coding_observation_key.md` | 觀察方向。 |
| `coding/guided_demos/` | 四個完整可執行的閱讀工具示例。 |

## 建議順序

1. 完成 Concept Practice。
2. 執行四個 Guided Demo。
3. 用實際 CLIP／LLaVA 來源位置填寫 Coding Practice。
4. 最後查看參考答案與觀察指引。
5. 將結果整理到 `../study_log.md`。

## 本週 Coding Practice 模式

本週採 Guided Code Reading Mode。程式用來理解結構化閱讀與驗證規則，不會替學生讀取論文、判定證據或填寫個人反思。
